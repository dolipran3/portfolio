# FlappyIa

## Présentation

FlappyIa est un clone du jeu Flappy Bird intégré au portfolio en tant que case projet : une expérience de jeu jouable directement dans la scène 3D, avec une composante « IA » qui met en avant l'apprentissage automatique.
